# 执行边界验收

作者可用虚构记录走查，并运行本包隔离测试；不得把它们当真实企业执行或用户反馈。

| 场景 | 应有结果 |
|---|---|
| 创建skill或只要执行计划 | 不开展业务操作，正式结果保持not_run |
| 指定对象身份不明 | 阻塞该路径，不偷偷换单或提升角色 |
| 有稳定脚本、历史成功和就绪报告 | 核实当前依赖、样本、身份、版本；不直接回填passed |
| UI显示成功但刷新丢失 | 保留即时及持久性断言反例，不用提示覆盖失败 |
| 一个分支通过，另一个失败 | 用例failed；分支证据均保留 |
| UI符合，必要后端唯一扣款断言无证据 | 后端断言blocked/inconclusive，整条不通过 |
| 预期未裁定或只有实现事实 | 不从当前值反推预期，不判passed/failed |
| 有失败断言且另一必要断言遗漏 | 保留failed并显式未完成，不因聚合失败掩盖漏项 |
| 重试各有部分通过 | 不跨attempt拼成全部通过；保留首轮和历史失败 |
| 写入超时，是否落单未知 | 首先稳定标识查证；无法确认则局部停止，不盲重放 |
| 并发、负例或删除测试 | 保留原测试条件；专属合法数据、首轮现场及实际副作用可追溯 |
| 初始阻塞，其他分支可执行 | 独立分支继续，首轮后逐项复查；无新信息不重复写 |
| 固定/动态回归受阻或人类取消 | 留显式状态、证据/授权，不标通过或删任务 |
| 部署/规则变更或范围缩减 | 新run保留旧记录及映射，旧通过不冒充当前覆盖 |
| 完成标记手填true，仍有not_run | 检查器计算completion_gate=false |
| 台账全处置但含failed/blocked | 可以记录收口，不能据此称全通过、零缺陷或可发布 |
| 只查看效果且无真实反馈 | 只读、未评价，不外发、不复测、不虚报节时 |

助手检查包括范围缺失、ID/引用、状态、证据定位、首次/后续attempt链、回归及阻塞复查关联、计数和收口。检查器不验证真实业务语义或截图内容；人工确认来源映射及证据充分性仍是执行者职责。

自测命令（在skill根目录）：

~~~powershell
python -X utf8 -B -m unittest discover -s tests -p "test_*.py" -v
~~~
