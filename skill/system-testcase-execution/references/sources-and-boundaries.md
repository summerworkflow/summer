# 来源与取舍

创作日期：2026-10-18。基于当前会话已经读取的本地技能和用户提供的enterprise-requirement-testing套件整理，无第三方业务执行代码或必需服务连接。

| 来源 | 借鉴 | 本技能取舍 |
|---|---|---|
| enterprise-browser-testing及其执行、台账文档 | 当前对象锚点、合法前置、写前意图、逐断言、首轮保留、恢复、回归与阻塞复查 | 扩展为依据实际可用工具执行已有用例；不捆绑浏览器、不继承自动生成Bug HTML或强制禅道流程 |
| 原套件共用约定及证据标准 | 授权与资料分离、独立预期、观察层边界、身份/输入/即时结果/持久性 | 不把E3/P0阈值当所有项目唯一规则；按项目及实际风险确定检查点，不把仅UI通过当整条全层通过 |
| 测试：前置准备 system-test-data-preparation 1.0.0 | 分支DATA/CAP、四维就绪、合法链、当前事实和失效复核 | 前置准备是独立职责；此处只核对和接续必要缺口，不重做整套准备规划 |
| 测试：AI用例转换器 system-ai-testcase-converter 1.0.0 | 真实脚本绑定、prepare/act/check、失败传播、未知写入先查证 | 转换制品不等于已执行；本包不提供或假称具备业务接口/脚本框架 |
| 测试：生成skills 1.0.0、skill-creator及既有格式参照 | 原子、版本化、可读、反馈查看、标准根目录和UI | 不引入私有SQL、硬编码项目路径、账号、仅显式调用或不必要审批 |
