# 测试：用例执行

版本：1.0.0。历史见 [版本记录](CHANGELOG.md)。调用 $system-testcase-execution。

## 职责与模式

输入已有用例、独立预期、前置交接和当前授权，执行选定范围，交付可追溯的实际结果与证据。准备、被测动作、检查分开；历史成功、脚本退出0及成功提示不能代替断言。

- “执行这些用例”：沿现有授权实际执行，复用合法前置和已核实的工具；缺失条件只阻塞依赖项。
- “恢复/重试/回归”：先读全部既有attempt和副作用，核实当前状态与版本，再新增记录；不重放未知写入。
- “制定执行计划”：只规划，不发业务请求，结果保持未执行。
- “查看执行效果”：按 [效果协议](references/outcomes.md) 只读指定台账与反馈，不重新执行。

创建或安装本skill不授予真实系统操作权限。授权按环境、对象、角色、动作及副作用判断；已有同范围授权继续适用，不逐条重复询问。未授权的付款、审批、删除、赋权、生产操作或外发留精确阻塞，不扩大范围。实际浏览器/接口/脚本操作需使用当前可用工具并先读其适用规范；本包没有业务执行器。

## 执行流程

1. **固定范围**：核对用例/规则/前置版本或实际指纹、部署、环境、角色、数据范围及授权。用户指定对象是范围锚点，不默换记录。未缩范围时覆盖输入中全部待执行项；工具不支持的项明确阻塞，不能静默剔除。排除项和变更范围保留理由。
2. **建立台账**：依 [台账与证据](references/ledger-and-evidence.md) 映射稳定用例、分支、必要断言和证据检查点，记录本轮选定范围。未确认预期不能从当前实现反推；仅规划不填真实ID或成功结果。
3. **逐分支核实前置**：检查当前身份、合法样本、关系、状态、关键值、隔离数量和易变条件。前置报告过期则复查；能力练习通过不代表样本存在。准备缺口给具体清单，独立用例继续；不为执行便利修改预期、补掉刻意无效条件或跳过合法业务链。
4. **实际操作并逐断言比较**：按 [执行与恢复](references/execution-and-recovery.md) 记录写前意图、对象与初态，一次做一个有后果的动作。收集输入、即时结果和必要回读/刷新证据，比较独立预期，按passed/failed/blocked/inconclusive/not_run记录。结论限实际观察层；按钮点击次数不等于请求或事务次数。
5. **保留首轮与局部恢复**：失败先存现场、实际值、错误及已发生副作用。未知写入先查证，不能盲重提或换号掩盖。恢复增加attempt并关联前次，技术调整须有新信息；独立剩余项继续。新部署/规则/环境基线另建运行，不借旧版通过。
6. **回归与阻塞复查**：首轮遍历全部选定项，执行适用的固定回归及本轮新增高风险/失败相关动态回归。初始阻塞项在首轮后逐项复查；条件已变化且获准时重试一次，无新信息不重复写入，保留仍阻塞及证据。回归项受阻或经人类授权取消要显式处置，不能当通过。
7. **核对交接**：检查所有选定分支、断言、回归和阻塞复查都有定位；通过须该范围全部必要项满足。用只读助手核对结构和收口情况，再交付执行记录、台账、证据索引、问题及残余数据。不手填完成标记，不以“记录收口”声称全部通过或可发布。

## 结果与检查器

默认在项目批次目录保存：用例执行记录.md、execution-ledger.json、执行效果反馈.md及evidence/证据；已有项目协议优先，必要时单独映射为检查器输入，不改源用例。Markdown说明对象、输入、前置、实际动作、逐断言预期/实际、证据、首轮与重试、回归、阻塞、副作用及隐藏层缺口。

只读助手要求Python 3.9+标准库，路径解析到实际skill目录：

~~~powershell
python -X utf8 -B scripts/review_execution.py "项目批次/execution-ledger.json" --format json
~~~

助手不联网、不读取证据引用、不扫描目录、不写回、不执行用例。它只核对**声明范围内**的台账；不能发现原用例被漏映射的断言，不能验证截图内容或授权真实性。退出0仅表示台账结构可分析，结果可以未完成或不通过。协议及判定规则见台账文档；不可用时按同一协议人工核对并注明未运行助手。

发布前/任务收尾按 [边界验收](references/acceptance.md) 自查；创作借鉴见 [来源边界](references/sources-and-boundaries.md)。

## 衔接与效果查看

执行记录可交给结果报告环节；疑似问题保留证据和排除准备/脚本/环境问题的状态，不自动宣布确认Bug、提交缺陷、接受残余风险、发布、清理数据或修改共享知识。确有当前授权的相应动作按范围处理。

用户可说：“查看这次用例执行效果，台账和反馈在……”。先展示错误通过、漏执行、证据缺失、未知副作用和未解阻塞，再展示真实使用评价。无反馈写未评价，无使用记录写尚无使用记录。作者自测不当真实业务效果，查看不安排回访或重新操作系统。
