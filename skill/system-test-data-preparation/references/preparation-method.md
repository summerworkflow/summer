# 从用例倒推前置

## 1. 先找准备终点

对选定用例/分支写清被测动作、动作前目标状态和独立预期依据，再倒推必要条件。已有设计或评审编号保持不变；没有编号时建立本批次映射。

合法链写成“源对象 → 允许的业务操作 → 关联或生成对象 → 核实动作前状态”。只列该业务实际需要的链；费用录入不必强加合同、付款或银行流水。来源不明的复制件不自动当有效原单。

例：评审后的用例要验证“审批通过后支付一次”。准备可以完成合法录单及授权审批，停在待支付；若用例要验证审批，则不能预先完成该审批。负例“缺附件不允许提交”应保留缺附件，其余条件满足，不能把目标无效条件当数据缺口补掉。

从源用例记录目标状态；准备中发现规则冲突则定位并交回裁定，不能为凑出可用数据改预期或把其他业务类型冒作目标类型。

## 2. 分配可用数据

每个DATA分配关联具体用例和分支，写清下列内容：

- 对象类型、业务方向/变更类型、目标状态、父子关系、归属组织/租户/角色范围。
- 主数据选择依据、关键金额/数量/币种/时间/精度及附件；计算依据与系统显示值分别记录，不能从系统结果反推预期。
- 复用/新建来源、每轮数量、共享或隔离方式、准备顺序、唯一标识与稳定对象ID。计划标识不是实际ID。
- 会被修改、消耗或不可回退的样本按用例/分支/轮次隔离；读取同一历史样本也需核对有效期、归属及实际内容。
- 重试样本与首轮样本的关联、可重用条件、清理或保留方案。不能静默清理失败证据。

并发重复提交类用例可能需要多个操作者指向同一个目标对象，不能为了隔离拆成多个对象而失去竞争条件。重试次数未知时列每轮需要，不虚构总量。资金、额度、库存等条件须足以暴露目标错误；例如额度过低导致重复扣减永远被余额拦住，会遮蔽待测风险。

既有历史记录默认只读复用；当前请求授权修改具体样本时，核对影响及保留首轮基线。合法测试夹具或接口若获准使用，必须说明其来源与适用环境；不能靠跳审批、改库强改业务状态或伪造下游成功冒充合法源链。

## 3. 能力与资产不是数据

CAP只描述可复用的准备能力，例如“从合法源单生成关联明细”。记录依赖CAP、影响的用例分支、适用业务类型、资产来源/版本、限制、最小验证练习和可观察成功标准。

资产成熟度 draft / validated / stable 与本轮状态分开：

| 本轮能力状态 | 含义 |
|---|---|
| 未知 | 未找到适用方法或尚未判断 |
| 有来源待验证 | 已找到配方/代码，还未在当前环境验证 |
| 历史验证待复核 | 有过去证据，当前部署、身份或页面尚未核实 |
| 需适配 | 方法与当前环境有差异，记录差异及适配位置 |
| 需指定输入 | 缺业务裁定、角色、环境控制或外部配合等精确输入 |
| 本轮验证通过 | 已有本轮环境/版本/身份范围匹配的成功证据和练习结果 |

依赖图须无重复CAP、无未定义依赖、无环；人工核对并在报告记录结论，不假称运行了校验程序。分支列自己的依赖，不把所有分支依赖的并集施加到每个分支。

检索仅在指定或任务已授权的资产范围内。使用脚本前检查真实入口、导入、配置、参数、版本、输出、联网/写入范围及幂等/恢复行为；隔离/停用资产只作历史参考，不能按名称直接运行。兼容修补保存在任务范围，不能默改共享脚本或把草稿提升为稳定资产。

## 4. 最小验证与异常恢复

仅规划时写明练习及成功标准，实际ID、时间和结果留空；不因“准备方案已完成”启动浏览器、接口或脚本造数。

获准实际准备后，先用可识别的隔离测试样本做足以证明该能力的最小练习；核对返回值之外的对象身份、归属、关系、状态和持久性，保存实际副作用。读能力同样需要身份和查询范围证据。实际生成的样本如拟给正式用例使用，另按该DATA行核实，不能只借能力练习结论。

写入超时或响应不明：记录首轮输入、稳定业务标识和已知副作用，先查询/重入核对是否已产生结果；不盲重提、不换号掩盖重复、不改预期。无法判断时阻塞该分支，给出所缺观察手段。

相同失败且没有新信息、归属/授权不明或继续可能叠加副作用时停止该路径。技术学习给与当前任务相称的尝试范围；已做尝试和失败阶段写入记录。新证据或适配后才恢复，不设置与项目无关的统一重试次数。

## 5. 处理阻塞

区分：操作能力/脚本不适配、数据/主数据缺失、角色或授权缺失、环境/配置不可用、异步状态或外部证据不可控、预期依据未确认、疑似产品问题。准备失败不能直接写产品Bug。

示例：环境自动通过审批，无法保留“审批中”状态。写明目标状态为何不可达及需要的授权环境控制/夹具，不用改库制造状态，也不因此阻塞不依赖该状态的查询分支。

先复用已知资料并做范围内的安全核实，仍缺人类业务裁定或控制能力时，提出最小请求：缺什么、卡在哪、影响哪些分支、已有证据、提供后怎么验。不要索要密码、泛泛要求整套模块培训或重复请求已具备的授权。

## 6. 有效性与交接

证据绑定准备批次、部署/配置、角色范围、对象ID和核实时间。环境、版本、角色、对象状态或共享数据变化会使关联结论待复查；无法确认部署版本时写未知及影响，不能默借历史版本。

执行前复查易变条件（状态、余额/额度、锁、时间窗口、角色有效性等）。准备报告反映其核实时间点，不能永久担保样本可用。将观察到的事实与计划和推断分栏交接，保留受影响用例/分支映射。
